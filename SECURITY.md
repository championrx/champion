# Security Policy

## Supported Versions

The latest version of this project receives security updates.

## Reporting a Vulnerability

If you discover a security issue:

1. Do not disclose it publicly.
2. Report the issue with detailed information.
3. Include steps to reproduce the problem if possible.

## Security Best Practices

- Keep dependencies updated.
- Review smart contracts before deployment.
- Test thoroughly before releasing new versions.
- Never expose private keys or sensitive credentials.
